## 向いている場面と解決する課題

明快な主体が一つあり、そばに関連する小物がいくつかある写真に向く：茶器一式、いくつかの瓶や壺、皿の果物、猫とその椅子、人とその手の中のもの。構図が弱い、背景が雑然、主体が小さい写真も救える——下半分で環境を消し、ものを正面か真横に向け、寄せて重ねた一群にし、静かに成立する夜の静物画にする。写真が通り、風景、室内なら、最も代表的な単体か断片を一つだけ描く。

要は、輪郭線のない平塗りシルエット、前後に重なる一群、見えない一本の水平線にそろう底辺、写真の最も暗い色を沈めた暗い地、低彩度のパステルグレーの色面、画面で唯一の暖かな白に近い明るい面、ドライなガッシュの細かな粒子、そして群れの横の暗い余白に置く細いセリフ体の大文字一語。場面の完全再現、背景を埋める、シルエットがばらばらに離れる、輪郭線、同じ明るさの面が並ぶ、立体的な陰影、真っ黒な地、グラデーション、彩度の高い飴色、整いすぎたベクターの縁は避ける。

## 使い方のコツ

- **まず一枚の見やすい写真から始める：** 主体・動作・関係が分かる画像を選んでから、出力形式と比率を決めます。
- **パラメータを一文でつなぐ：** 「上下 / 左右 / デザインのみ + 16:9 / 3:4 / スマホ壁紙」のように指定し、PC・タブレット・スマートウォッチのサイズも追加できます。
- **残したい内容を明示する：** 人物、物、動作、関係、文字を指定し、レイアウトを細かく縛りすぎずスタイルに任せます。
- **文字の方法を選ぶ：** 画像から自動生成、`--text exact --copy` で逐字固定、または `--text none` で文字なしにできます。
- **写真領域とデザイン領域を伝える：** 上下・左右では写真を残す側と再設計する側を指定し、デザインのみ・壁紙では全画面を再設計すると伝えます。
- **一枚で試してから一括処理する：** モード、比率、文字、言語を一枚で確認し、同じ設定をフォルダに適用します。比較しやすいよう一度に一つだけ変更します。

## はじめに

GitHub からインストール：

```bash
npx skills add https://github.com/nevertoday/xxd-panel-345 --skill xxd-panel-345
```

インストール後に Agent セッションを再起動し、`$xxd-panel-345` を呼び出します。ユーザー単位の Codex には `--global --agent codex --yes` を追加できます。

```text
/xxd-panel-345 photo.jpg --mode top-bottom --size 3:4 --text prompt --locale ja-JP
/xxd-panel-345 photo.jpg --mode left-right --size 16:9 --text prompt --locale en-US
/xxd-panel-345 photo.jpg --mode design-only --size 9:16 --text none --prefs off
```

完全な実行契約は [SKILL.md](SKILL.md)、実行アダプターは[英語](references/xxd-panel-345-prompt.en.md)／[中国語](references/xxd-panel-345-prompt.zh-CN.md)を参照してください。

## クイック判定

元写真の同一性を保ちながら構図を再演出し、素材の特徴と意図的な余白を両立。指定文・自動文案・文字なし、単画像・再帰的フォルダー処理、下記の4出力モードに対応します。

## 4つの出力モード

- `top-bottom`：全幅の上下2領域のみ。実写を上、デザインを下に置き、各50%。
- `left-right`：全高の左右2領域のみ。実写を左、デザインを右に置き、各50%。上下構成へ回転しません。
- `design-only`：全画面を Panel 345 のデザイン翻訳にし、写真は見えない参照にします。
- `wallpaper-pack`：スマートフォン、iPad、デスクトップ、時計を端末ごとに生成。`linked` または `independent` を選べます。

モードと比率は複数指定できます。`1:1`、`3:4`、`4:3`、`4:5`、`5:4`、`2:3`、`3:2`、`9:16`、`16:9`、`21:9`、`5:7`、`7:5`、正確なピクセルに対応します。文字はプロンプト生成、指定文の逐字使用、なしから選べます。フォルダ入力では各画像を分離して処理し、PNGを一つの新しいタスクフォルダへ置きます。
